# Словарь Vector Work

Единственное определение терминов. Все публичные тексты (README, orchestrator,
agent-description, STATUS, REGISTRY) ссылаются сюда, а не на память.

**Источник правды — дерево.** Пока текст не исправлен, истиной считается дерево,
а не README.

## Сущности

| Термин | Определение | Как считается |
|---|---|---|
| **Домен** | каталог `skills/cowork-roles/<имя>/` | `ls -d skills/cowork-roles/*/` |
| **Роль организации** | домен, для которого есть контракт `profiles/<домен>.md` | домены минус витрины |
| **Витрина** | `partner-built/` — навыки под конкретные системы, не под функцию организации | явный список в `_tree.SHOWCASE` |
| **Навык Cowork** | файл `SKILL.md` внутри `cowork-roles/` | `rglob('SKILL.md')` |
| **Свой навык** | каталог в `skills/` вне `cowork-roles/` со своим `SKILL.md` | `_tree.own_skills()` |
| **Контракт** | должностная инструкция роли: права, запреты, проверки, формат сдачи | `profiles/<домен>.md` |
| **Плейбук** | позиции организации по договорам и NDA | `profiles/legal-playbook.md` |
| **Типовое** | значение-каркас, помеченное `[Т]`; НЕ позиция организации | счёт `[Т]` |
| **Открытое решение** | поле, которое нельзя вывести из дерева; помечено `<РЕШЕНИЕ` | счёт `<РЕШЕНИЕ` |
| **Плейсхолдер** | незаполненный `<…>` в тексте контракта | счёт `<[а-яё]…>` |

## Права (least privilege)

    база для всех               file, skills, memory
    по требованию домена        connections, browser, terminal
    запрещено всем без исключений  delegate_task, cronjob_manage, computer_use

Браузер по тексту навыка **не доказывается** (эвристика давала ложные срабатывания:
«открывается в браузере», «сайт-визиты», «кликабельные карточки»). Выдаётся решением
владельца и перечисляется явно.

## Правила дома

- Числа берутся из дерева (`scripts/_tree.py`), не из памяти и не из README.
- Устаревшее число — дефект, роняющий CI, а не стилистика.
- Каждый класс дефекта закрывается проверкой в `validate_structure.py` **и** мутацией
  в `mutation_check.py`. Проверка, которая «должна ловить», но не ловит, — баг.
- Правка тела контракта без нового ревью роняет приёмку (отпечаток `body_sha256`).
- Ревью от имени человека не выдумывается: принятое пакетом описывается как принятое пакетом.
