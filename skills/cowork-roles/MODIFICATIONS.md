# Изменения относительно апстрима (Apache-2.0 §4(b))

Копия ролей взята из `anthropics/knowledge-work-plugins` @ закреплённой ревизии
(см. `upstream.lock.json`). Apache-2.0, §4(b), требует **отмечать изменённые
файлы**. Этот файл — такое отмечание: перечислены все отличия копии от апстрима,
с причиной. Проверяется `scripts/check_upstream.py --check` (пофайловые хэши в
`upstream.lock.json`) и проверкой S24.

## Что совпадает с апстримом

Всё остальное — побайтово. Пофайловые хэши каждого файла домена хранятся в
`upstream.lock.json` → `files`, поэтому расхождение видно без сети:

    python3 scripts/check_upstream.py --check     # сверка закоммиченного с локом
    python3 scripts/check_upstream.py --pin [sha] # перепинить на ревизию (нужен клон)
