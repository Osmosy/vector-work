# AGENTS.md — правила для AI-агентов в этом репозитории

Инструкция для агентов (Hermes, Claude, Codex и любых других), которые читают или
правят этот репозиторий. Отличается от runtime-инструкций: здесь правила доступа
и работы с контентом, а не поведение роли.

## Что это

Vector Work — виртуальные сотрудники на базе Hermes Agent. 18 каталогов Cowork
(17 ролей организации + витрина partner-built), 252 навыка. Роли описаны
контрактами в `profiles/`.

## 1. Источник правды — дерево, не README

Числа берутся **из дерева** (`scripts/_tree.py`), а не из памяти и не из README.
Пока текст не исправлен, истиной считается дерево. Определения — `docs/VOCABULARY.md`.

Устаревшее число — дефект, роняющий CI, а не стилистика.

## 2. Генераторы пишут файлы

`scripts/build_registry.py` и `scripts/build_contracts.py` **перезаписывают**
`profiles/REGISTRY.md`, `profiles/registry.json` и контракты доменов. Запускать
только в рабочей копии. После прогона `git status --short` — изменения коммитить
осознанно.

Порядок после любой правки состава или прав:

```bash
python3 scripts/build_registry.py
python3 scripts/build_contracts.py
python3 scripts/build_reviews.py     # только после изменения приёмки
python3 scripts/validate_structure.py
python3 scripts/mutation_check.py
```

## 3. Правило дома: проверка + мутация

Каждый найденный класс дефекта закрывается **проверкой в `validate_structure.py`
И мутацией в `mutation_check.py`**, а не только правкой текста. Проверка, которая
«должна ловить», но не ловит, — это баг, а не мелочь. Мутация обязана дать ERROR.

## 4. Приёмка не выдумывается

- Ревью от имени человека **не пишется**, если человек его не выносил.
- Принятое пакетом описывается как принятое пакетом (поле `applied: BATCH`), а не
  шаблонной фразой «посмотрел через страницу».
- Приёмка привязана к телу контракта отпечатком `body_sha256`. Правка тела без нового
  ревью роняет S12.

## 5. Типовое ≠ решение владельца

- `[Т]` — типовой каркас, заменяется решением владельца.
- `<РЕШЕНИЕ` — решение нельзя вывести из дерева; спросить.
- Решения владельца агент сам не принимает: готовит варианты.

## 6. Права (least privilege)

    база для всех               file, skills, memory
    по требованию домена        connections, browser, terminal
    запрещено всем              delegate_task, cronjob_manage, computer_use

Права вычисляет `scripts/_tree.py`. Браузер по тексту навыка не доказывается —
только явным решением владельца.

## 7. Не хранить PII и секреты

Репозиторий — исходники навыков. Клиентские документы, ПДн, токены, пароли —
вне репозитория. Перед пушем скан на секреты по диапазону коммитов.
